# Sejal Chaudhari — Portfolio

Personal portfolio website. Show skills, projects, resume, contact.

## Built With

- HTML, CSS, JavaScript
- Bootstrap 5
- AOS (scroll animations)
- Typed.js (typing effect)
- Isotope (project filter)
- GLightbox (image preview)

## Sections

- **Hero** — intro + typed animation
- **About** — bio, location, currently learning
- **Resume** — education & skills
- **Projects** — filterable project gallery
- **Contact** — contact form + info

## Run Locall

Just open `index.html` in browser. No build step needed.

> Contact form needs PHP server + pro library to work. Static hosting = form won't send.
